# Cloud Run

This folder contains reproducible Cloud Run scenarios implemented with Terraform and supporting files.

Structure
- `scenario-name/files/` — each scenario lives in its own subfolder; put Terraform code and scenario README under `files/`.

Example
- `cloud-run/sidecar-packet-capture/files/` — contains `README.md`, `main.tf`, and cleanup helpers.

See the repository root README for general guidance on prerequisites, running scenarios, and contribution steps.
