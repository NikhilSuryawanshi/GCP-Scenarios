# Cloud Functions

This folder contains Cloud Functions scenarios demonstrating function triggers, permissions issues, and runtime edge cases.

Structure
- `scenario-name/files/` — place Terraform code, a scenario `README.md`, and any helper scripts inside the `files/` folder.

Example
- `cloud-function/pubsub-retry-loop/files/` — includes `README.md`, `main.tf`, and cleanup steps.

Consult the root README for prerequisites and common workflows.
