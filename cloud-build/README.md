# Cloud Build

This folder holds Cloud Build scenarios (build pipelines, triggers, and edge cases) with Terraform code and documentation.

Structure
- `scenario-name/files/` — each scenario lives in its own subfolder; include Terraform config and a scenario `README.md`.

Example
- `cloud-build/docker-cache-misconfig/files/` — contains `README.md`, `main.tf`, and helper scripts.

Refer to the root README for repo-wide conventions and run instructions.
